# Исследовательская работа по оптимизации вычислений необходимых для построения множества Мандельброта

## Описание
В рамках данной работы было реализовано построение множества Мандельброта с графической визуализацией. В связи с тем, что его построение требует значительных объемов вычислений, было проведено исследования для выявления способов позволяющих кратно повысить их скорость. Работа выполнена на языке **C** в операционной системе **Windows 11**. Для визуализации множества была использована графическая библиотека **TXLib**. Компиляция производилась при помощи **g++**.

Основной прирост производительности был получен за счёт понимания и грамотного использования возможностей процессора. Реализация основана на использовании **Intrinsic function** - особый вид функций, предоставляемых компилятором, которая заменяется им на высоко оптимизированную инструкцию процессора. Были использованы функции из семейства **SIMD** позволяющие параллельно работать с вектором данных. Для корректной работы оптимизации необходима поддержка процессором расширения **AVX512**. Разработка и тестирование велась на процессоре **AMD Ryzen 7 8845H** поддерживающим данное расширение.
